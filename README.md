# 🌐 Portfolio Website

A modern and responsive personal portfolio website showcasing my projects, skills, and experience in software development, AI, and web technologies.

---

## 🚀 Features

- Fully responsive design (mobile + desktop)
- Animated UI with smooth transitions
- Project filtering system (AI, Web, ML, Backend, etc.)
- Show more / load more functionality
- Interactive navigation with active section highlighting
- Contact form with validation
- Clean and modern UI design

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox + Grid + Animations)
- JavaScript (Vanilla JS)
- Font Awesome Icons
